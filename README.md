**A legacy Minecraft 1.7.10 plugin suite for Faction PvP servers**

Alterya was created for a Faction PvP Minecraft server and is split into three Bukkit/Spigot plugins:

| Plugin | Purpose |
| --- | --- |
| **AlteryaCore** | Economy, ranks, shops, homes, teleportation, trades, and server utilities |
| **AlteryaFaction** | Faction territories, relations, power, homes, capes, and management commands |
| **AlteryaModeration** | Staff tools and graphical moderation interfaces |

## Download

The latest source-tagged release is available on the [Releases page](https://github.com/clementgvs/Alterya/releases/latest).

Compiled plugin jars are retained in [`compiled (.jar)`](compiled%20(.jar)).

## Project layout

```text
Alterya_Core/       Core plugin
Alterya_Faction/    Faction plugin
Alterya_Moderation/ Moderation plugin
compiled (.jar)/    Compiled plugin jars
```

## Compatibility

These plugins target Bukkit/Spigot **1.7.10** and use an old Java and plugin API. They are not compatible with modern Minecraft server versions without substantial updates.
